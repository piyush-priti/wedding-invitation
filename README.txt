PIYUSH & PRITI — STATIC WEDDING INVITATION

HOW TO OPEN
1. Extract the ZIP folder.
2. Double-click index.html.
3. No Python, Node.js, React, or local server is required.

FILES
- index.html: page structure and all section markup
- css/style.css: theme and custom styles
- js/app.js: theme studio, interactions, countdown, ceremony modal, and other logic

NOTES
- Internet is needed for Google Fonts and the Tailwind CDN used by the original design.
- Image files were not present in the supplied original HTML. If you have Main.jpeg, Memory1.jpeg, Memory2.jpeg, place them in the location expected by their src paths or update those paths in index.html.
- Section markup is embedded into index.html so the file can be opened directly without fetch/server restrictions. CSS and JavaScript remain separate files.
